# ref — 소스 · 레퍼런스 UI 보관소

moto UI 작업의 **디자인 소스와 레퍼런스 이미지**를 모아두는 상시 폴더.
(코드가 아니라 참고용 자료. 앱 번들에는 포함되지 않음 — 서빙이 필요한 애셋은 `public/`에 둔다.)

## 현재 파일
- `레이아웃 레퍼런스.png` — 아임웹 스타일 3단 대시보드 레이아웃 레퍼런스 (현재 `/dashboard` 뼈대의 기준)
- `홈 대시보드.png` — 초기 Home 대시보드 기획안
- `추구미.png` — 지향하는 비주얼/톤 레퍼런스
- `개발자말.png` — 개발자 코멘트/요구 메모

## 규칙
- 새 화면 레퍼런스는 여기에 추가.
- 로고 등 **앱에서 실제 렌더되는** svg/이미지는 `public/`으로 (예: `public/PlayoutPlus.svg`).
- 값(토큰) 기준 문서는 상위 `moto/DESIGN.md`.
